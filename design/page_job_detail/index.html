Mô tả công việc (JD)

Tham gia phát triển hệ thống web ứng dụng tuyển dụng trực tuyến quy mô lớn phục vụ hàng triệu người dùng.

  • Xây dựng và bảo trì các RESTful API hiệu năng cao bằng Laravel 11, áp dụng Eloquent ORM, Service Layer và Repository Pattern.
  • Phát triển giao diện phía client bằng ReactJS / Next.js 14 App Router, tích hợp Tailwind CSS và TypeScript.
  • Tích hợp cơ chế realtime chat và thông báo qua WebSocket (Laravel Reverb / Pusher).
  • Tối ưu hóa cơ sở dữ liệu MySQL, index các trường tìm kiếm và caching với Redis.
  • Phối hợp cùng đội ngũ AI để kết nối API Gemini 1.5 Flash phục vụ phân tích CV tự động.

Yêu cầu chuyên môn

  • Có từ 3 năm kinh nghiệm làm việc thực tế với PHP (Laravel framework) và JavaScript/TypeScript.
  • Thành thạo cấu trúc dữ liệu MySQL, viết Query tối ưu và thiết kế Database Schema chuẩn hóa.
  • Kinh nghiệm vững chắc với Next.js (SSR, Server Components, Client State).
  • Hiểu biết tốt về bảo mật web: ngăn chặn SQL Injection, XSS, CSRF, Token Authentication (Sanctum/JWT).
  • Khả năng đọc hiểu tài liệu kỹ thuật tiếng Anh tốt (tương đương TOEIC 650+).

Quyền lợi & Đãi ngộ

  • Mức lương cạnh tranh từ 25 - 40 triệu VNĐ/tháng (xét tăng lương 2 lần/năm).
  • Thưởng tháng 13 + thưởng hiệu quả kinh doanh dự án lên tới 2-3 tháng lương.
  • Gói bảo hiểm sức khỏe FPT Care cao cấp cho nhân viên và người thân.
  • Trang bị máy tính Macbook Pro hoặc Laptop chuyên dụng cấu hình cao.
  • Chính sách làm việc linh hoạt (Hybrid Remote 2 ngày/tuần).
